# MCPulse social kit

Generated by `node scripts/social.mjs`. Do not touch these files by hand — edit
the script and re-run it, so the mark, the cyan and the tagline stay one
decision rather than fourteen.

Every asset is drawn from `src/components/Logo.astro`'s path and `src/lib/og.ts`'s
palette, at each platform's real pixel size.

## Profile pictures

| File | Size | Use |
| --- | --- | --- |
| `logo-dark-1000.png` | 1000×1000 | The default avatar — X, LinkedIn, GitHub, npm, Discord |
| `logo-dark-400.png` | 400×400 | Where an upload is capped small |
| `logo-light-1000.png` | 1000×1000 | On a light or white profile chrome |
| `logo-transparent-1000.png` | 1000×1000 | Over someone else's background |
| `logo-transparent-512.png` | 512×512 | Same, small |

The tile is square with a 22% radius; platforms that crop to a circle take the
corners and nothing else — the mark sits well inside the inscribed circle.

## Headers

| File | Canvas | Safe area held |
| --- | --- | --- |
| `x-header-1500x500.png` | 1500×500 | 1180×340 |
| `linkedin-company-1128x191.png` | 1128×191 | 900×165 |
| `linkedin-personal-1584x396.png` | 1584×396 | 1200×320 |
| `github-org-1280x640.png` | 1280×640 | 1060×460 |
| `youtube-channel-2560x1440.png` | 2560×1440 | 1546×423 |
| `facebook-cover-1640x624.png` | 1640×624 | 1200×440 |
| `og-default-1200x630.png` | 1200×630 | 1000×460 |

The lockup is centred inside the **safe area**, not the canvas. That is the
difference between a header that survives and one where X pastes the avatar
over the wordmark or a phone crops YouTube down to a blank strip.

`og-default` is **also written to `public/og-default.png`** by the same script,
and the site serves it: `src/lib/og.ts` uses it as the `og:image` for any page
without a card of its own — today that is `/404` only. Every other page gets its
own card, with its own title, from `og.ts`.

Do not copy it into `public/` by hand. `social.mjs` writes both, so the served
file cannot stop matching the mark.

## Lockup

| File | Use |
| --- | --- |
| `wordmark-dark.png` | Mark + wordmark, transparent, for dark backgrounds |
| `wordmark-light.png` | The same for light backgrounds |

Both are trimmed to their own ink with a small margin, so they can be sized by
their image box.
